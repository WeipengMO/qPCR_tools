# qPCR Tools Web App

一个纯前端 qPCR 结果分析工具。直接用浏览器打开 `index.html` 即可使用，不需要安装依赖、启动服务或上传数据。

页面包含两个相互独立的分析模块：

- `对照归一`：经典 `2^-ΔΔCt` 分析，用于比较目标基因相对对照组的表达变化。
- `全基因表达量`：展示多个 target genes 的内参归一表达量，用 `ΔCt`、`-ΔCt` 或 `2^-ΔCt` 描述表达谱，不依赖对照组。

## 数据格式

粘贴 CSV、TSV，或从 Excel 复制表格。必须包含以下表头：

```text
sample,group,gene,ct
```

也可以使用中文表头：`样本,分组,基因,Ct值`。

- `sample`: 生物样本编号
- `group`: 实验分组
- `gene`: 基因名，包括目标基因和内参基因
- `ct`: Ct 值

同一样本、同一组、同一基因的多行 Ct 会按技术重复取平均。

qPCR 仪器导出的 `Undetermined`、空值或其他非数字 Ct 会被自动忽略，不参与任何模块计算。页面会在 warning 中列出被忽略的行号、sample/group/gene 和原始 Ct 值。

如果某组技术重复 Ct 极差超过 `0.5`，页面会显示 warning 提示检查异常值；该提示不阻断分析，计算仍会使用技术重复平均 Ct。

## 模块一：对照归一 2^-ΔΔCt

适用于比较一个 target gene 相对内参和对照组的表达变化。

计算步骤：

1. 技术重复取平均 Ct
2. `ΔCt = target Ct - reference Ct`
3. 计算对照组平均 `ΔCt`
4. `ΔΔCt = sample ΔCt - control mean ΔCt`
5. 相对表达量为 `2^-ΔΔCt`

单内参模式下，`reference Ct` 是所选内参基因 Ct。双内参模式下，使用两个内参基因平均 Ct 的算术平均值作为 `reference Ct`。

统计检验在 `ΔCt` 尺度上进行：

- 非对照组 vs 对照组：Welch t-test
- 多组总体差异：one-way ANOVA

如果任一参与分析的组只有 1 个生物学重复，页面会显示 warning。只有所有组都满足 `n >= 2` 才进行 ANOVA；Welch t-test 会对每个处理组单独判断，只有该处理组和对照组都满足 `n >= 2` 才计算 p 值。统计不足时结果只用于观察表达趋势。

当前统计检验只支持独立样本设计。配对样本、重复测量或嵌套实验设计需要使用专门的统计模型，不能直接按这里的 Welch t-test 或 one-way ANOVA 解释。

## 模块二：全基因表达量

适用于展示一组 target genes 在不同 group 中的内参归一表达水平。该模块不使用对照组，也不做统计检验。

计算步骤：

1. 技术重复取平均 Ct
2. 对每个样本计算内参 Ct
3. `ΔCt = Ct_target - Ct_ref`
4. 可视化时选择以下 Y 轴之一：

```text
2^-ΔCt
-ΔCt
2^-ΔCt × 10³
```

默认 Y 轴是 `2^-ΔCt`。`2^-ΔCt × 10³` 仅用于把数值放大显示，便于阅读；不改变样本之间的相对关系。

全基因模块支持：

- 单内参或双内参
- 自动从展示基因中排除所选内参基因
- 默认展示所有 target genes
- 用标签框筛选基因：点击 `×` 可移除，输入基因名后回车可添加，点击“全选”恢复全部
- 图表分组可选：默认按样本分组（每个 group 内显示不同基因），也可按基因分组（每个基因内显示不同 group）
- 误差线可选 SEM、SD 或无
- 显示或隐藏样本数据点

## 使用

打开项目目录中的 `index.html`：

```text
index.html
```

点击“载入示例”可以载入示例表格。全基因表达量模块的示例包含两个内参基因和 4 个 target genes，便于测试分组 barplot。

页面内可以下载 SVG 图和结果 CSV。CSV 内容会随当前模块变化：

- 对照归一模块导出样本 `2^-ΔΔCt` 明细和分组统计；分组统计包含 `error_lower`、`error_upper` 和 `error_mode`，用于表达 fold change 上的不对称误差线
- 全基因表达量模块导出 `group × gene` 汇总和样本级 `ΔCt / 2^-ΔCt` 明细

## 图表控制

对照归一模块支持：

- 选择 target gene、reference gene 和 control group
- 单内参或双内参
- 显示或隐藏样本数据点
- 显示或隐藏柱状图平均值
- 自定义对照组和处理组颜色
- 在 `Y = 1` 位置显示参考虚线
- 对照组固定排在最左侧

全基因表达量模块支持：

- 选择内参基因和双内参
- 筛选展示基因
- Y 轴选择 `2^-ΔCt`、`-ΔCt` 或 `2^-ΔCt × 10³`
- 图表分组可选按样本分组或按基因分组，默认按样本分组
- Y 轴根据当前可见基因自动缩放
